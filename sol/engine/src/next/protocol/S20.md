### Pace (Harmony S20, #1617, #1601; `next/pace.ts`)

Behind `ui.next`, answered only to Sol's own windows (anything else hears `next.refused`). Readings, not records: nothing is sent anywhere.

- `next.pace` (face → engine, no fields) → `next.pace {seats: [{seat, used: [{window, pct, resetsAt, asOf, stale}], heading, take, notCounted, warn, rung}]}` to the asker. `claude` and `codex` are always named. `used` is per vendor window (`five_hour`, `seven_day`, …). `heading` is percent (used ÷ share of the window passed, the worst window; `null` before 10% of a window has passed or when stale). `notCounted: true` for a seat with no number from its vendor, never 0. `warn` is the vendor's `allowed_warning` / `rejected`. `rung`: 0 nothing waits, 1 night runs wait, 2 new runs wait too.
- `next.pace.set {take?: "calm"|"steady"|"all-out", perAI?: {seat: take|null}}` → `next.pace` to every window. Lines (percent): calm 70/70, steady 90/90, all-out 100/100 (nights wait at heading ≥ first, new runs at used ≥ second, or at the vendor's refusal). Steady until set.
- `next.run.anyway {run}` → `next.run.anyway {run, ok: true}` to the asker. That run goes whatever the pace.
- Each wait is one Diary line (`next/diary.ts`, `via: "pace"`), once per run and rung, with `embed: {pace: {run, rung}, press: {label: "Run it anyway", send: {type: "next.run.anyway", run}}}`. Running work always finishes.

For the run starters (outside `next/`, not wired by this slice): `mayStart(home, {run, seat, night?, running?})` returns `{go}` or `{go: false, rung, why}` and writes the wait. `notedClaude(home, sdkRateLimitEvent)` keeps the Agent SDK's `rate_limit_event`; until a stream hands it here, Claude reads "not counted". Files: `SOL_HOME/next/pace/{take,claude,anyway,waits}.json`.
