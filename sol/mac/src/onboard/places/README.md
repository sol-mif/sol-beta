# places: the one reader's store reader

What the computer holds is found by the one reader, the one onboarding's explorer (`../explore.mjs`), which runs this store reader beside it. It lived under `home/folders/places` until the tour went (#1223); the finder that was here (`find.mjs`, `known.json`) went with #1217. `fake-home.mjs` stays: the store reader's tests build their made-up homes with it.

# read: the store reader (#1071)

**Reads**, read-only, one app's own store on a Mac, looked for in `--from` (Sol.app's copy, `places_copy([store])`) first, then the home: Notes (`NoteStore.sqlite`: folder names, note titles, when each changed), Calendar (`Calendar.sqlitedb`: calendar names, event titles and start times from 14 days back to `--days` ahead), WhatsApp desktop (`ChatStorage.sqlite`, and `ContactsV2.sqlite` for a chat with no name: the name of each chat and when it was last active) and Messages (`chat.db`: each chat's name, or its handle when it has none, and when it was last active). Each store and its `-wal`/`-shm` are copied to a temp dir and opened read-only.
**Never reads** a note's body, an event's place, notes or guests, or a word of any message. The chats are not opened at all without `--chats names`, which the person gives by saying yes to "I can read the names of your chats and when each was last active, never what was said." WeChat keeps its store encrypted: it is only looked for, never opened. On Linux and Windows there is no reader: every store is `missing`.
**Never writes** anywhere but `--out` and that temp dir, which it deletes. It never opens the network.
**Run**: `node read.mjs --store notes|calendar|whatsapp|messages|wechat --out <file> [--from <dir>] [--home <dir>] [--chats names] [--days 60]`. The shape is written in `read.mjs`'s head; `ok:false` comes with `need`: `switch` (macOS keeps it closed until Sol has Full Disk Access), `encrypted` (WeChat), `format` (a table or column not as expected; the reason in `note`), `missing` (not on this computer), `ask` (the chat question). Test with `node --test read.test.mjs`, on made-up homes from `fake-home.mjs` (`makeStoreHome`) with small SQLite stores in these apps' table shapes.
